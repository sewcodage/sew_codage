# Button

Boutons d'action : principal (noir), secondaire (contour), clair sur fond sombre, et WhatsApp.

- **Principal** (`ink-900`, texte `on-dark`) : une seule action principale par écran (« Add to cart », « Shop the set of 3 »).
- **Secondaire** (contour `ink-900`) : action d'appui (« Buy with Apple Pay » quand le bouton Apple natif n'est pas disponible, « Discover the kit »).
- **Sur fond sombre** (`on-dark`, texte `ink-900`) : dans le bloc de clôture.
- **WhatsApp** : contour, avec l'icône. Le numéro est aussi affiché en texte, car le lien peut ne pas s'ouvrir partout.
- Hauteur 48px minimum, `radius-sm`, style `button`. Pleine largeur sur mobile.
- Libellé = ce qui se passe (« Add to cart », pas « Continue »). En arabe : « أضيفي إلى السلة ».
