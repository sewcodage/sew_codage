# DeliveryNote

Bloc qui annonce le délai réel de livraison et le seuil de livraison offerte, placé juste au-dessus du bouton d'achat.

- Fond `sand-100`, icône camion à traits (en miroir en arabe), texte `body-sm`, délai en gras.
- Le délai vient des commandes réelles (échantillons puis premières ventes). Tant qu'il n'est pas mesuré : `[X–Y] days`.
- Pourquoi là : un délai caché est la première source de litiges et de remboursements en dropshipping.
