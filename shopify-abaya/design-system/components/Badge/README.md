# Badge

Petite étiquette en capitales pour signaler une offre : « MOST POPULAR » (lot de 3), « NEW », « GIFT READY » (kit).

- Fond `ink-900`, texte `on-dark`, style `eyebrow`. Variante discrète : contour `gold-700`, texte `gold-700`.
- Un seul badge par carte. Jamais de badge de réduction inventé (« -50 % ») sans prix barré réel.
- En arabe : « الأكثر طلبًا », sans capitales ni espacement de lettres (l'arabe n'en a pas).
