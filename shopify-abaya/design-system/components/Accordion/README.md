# Accordion

Sections dépliables pour les détails produit et la FAQ, construites avec `<details>` et `<summary>` (accessibles sans script).

- Ligne de 52px minimum, titre en `body-strong`, filet `border-subtle` entre les lignes, signe plus ou moins à droite (à gauche en arabe).
- Le premier bloc « Details » est ouvert par défaut sur la fiche produit.
- Les réponses de FAQ reprennent uniquement des faits vérifiés (dimensions, matière, délais réels, politique de retour).
- Ajouter le balisage FAQPage (données structurées) sur la page Aide en phase 6.
