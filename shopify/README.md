# Boutique Shopify : page produit premium

- `templates/product.json` : modèle de page produit du thème « Helio – Page produit premium » (copie non publiée du thème Helio).
- `scripts/make_images.py` : retouche des photos fournisseur et création des visuels (7 couleurs, détails, avantages).
  Usage : `python3 scripts/make_images.py <dossier>` avec les photos d'origine dans `<dossier>/img/orig`.
- `images/` : visuels marketing générés.
